# Thesis

The written thesis manuscript, organized so that it mirrors the same
narrative as the rest of the repository: problem → state of the art →
data → methodology → experiments → results → discussion → conclusion.

```
thesis/
├── chapters/
│   ├── 01_introduction/
│   ├── 02_state_of_the_art/
│   ├── 03_data/
│   ├── 04_methodology/
│   ├── 05_experiments/
│   ├── 06_results/
│   ├── 07_discussion/
│   └── 08_conclusion/
├── figures/       ← figures used in the manuscript
├── tables/        ← tables used in the manuscript
└── references/    ← bibliography
```

This folder is expected to remain mostly empty until writing begins in
earnest; the format of the manuscript itself (e.g. LaTeX, Markdown,
Word) has not yet been decided.
