# Invasive Plants Mapping

Mapping and analysis of invasive plant species distribution.

## Project Structure

```
invasive-plants-mapping/
│
├── data/           # Raw and processed datasets
├── notebooks/      # Jupyter notebooks for exploration and analysis
├── src/            # Source code (scripts, modules, utilities)
├── docs/           # Documentation, including research questions
└── results/        # Outputs: figures, maps, tables, reports
```

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
